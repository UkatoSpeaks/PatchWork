# stats (toy repo)

A small, working statistics package for testing Patchwork. Its test suite
passes. `ISSUE.md` asks for a new feature, `median()`, so the tester agent has
to write tests before the coder implements it.

Don't add `median()` by hand in this copy. Patchwork's own test suite
(`tests/test_toy_repo.py`) checks that it is still missing.
